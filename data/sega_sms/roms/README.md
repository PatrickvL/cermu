# Sega Master System ROM Files

The Sega Master System is a cartridge-based system. Some models include
a built-in BIOS ROM, but it is not required for emulation — games boot
directly from cartridge ROM images.

## System ROMs (Optional)

| Filename | Size | Description |
|----------|------|-------------|
| `bios.sms` | 8–256 KB | Master System BIOS (model-dependent, optional) |

The BIOS provides the "Snail Maze" built-in game on some models and
performs region/license checks. It is not required to run cartridge games.

## Cartridge ROMs

Place cartridge ROM images (`.sms`, `.rom`, `.bin`) in this directory
or load them via the emulator's file menu.

## Where to Obtain

- **Dump from original cartridges** — if you own Master System games
- **MAME ROM set** — `sms.zip` contains BIOS images for various models
- **SMS Power!** — the definitive Sega 8-bit community
  - https://www.smspower.org/
