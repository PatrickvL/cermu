# Memotech MTX ROM Files

The Memotech MTX500 and MTX512 require an OS+BASIC ROM to boot. These ROMs
are copyrighted by Memotech and are **not** included in this repository.

## Required ROMs

### MTX500

| Filename | Size | Description |
|----------|------|-------------|
| `mtx500.rom` | 16 KB | MTX500 OS + BASIC ROM |

### MTX512

| Filename | Size | Description |
|----------|------|-------------|
| `mtx512.rom` | 16 KB | MTX512 OS + BASIC ROM |

## Alternative Filenames Accepted

- **MTX500:** `mtx500.rom`, `mtx.rom`, `MTX.ROM`
- **MTX512:** `mtx512.rom`, `mtx.rom`, `MTX.ROM`

Both variants share this directory. The emulator selects the correct ROM
based on the system variant chosen at startup.

## Missing Files

| Filename | Size | Description |
|----------|------|-------------|
| `mtx500.rom` | 16 KB | **MISSING** — MTX500 OS + BASIC |
| `mtx512.rom` | 16 KB | **MISSING** — MTX512 OS + BASIC |

## Where to Obtain

- **MAME ROM set** — `mtx512.zip` contains the ROM images
- **Dump from original hardware** — if you own a Memotech MTX
- **Memotech MTX community** — preservation and resources
  - http://www.primrosebank.net/computers/mtx/mtx.htm
  - https://mtxworld.dk/
