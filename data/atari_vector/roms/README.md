# Atari Vector Arcade ROM Files

> **Note:** The Atari Vector arcade emulation supports several variants.
> ROM archives sourced from [ionpool.net](https://arcarc.xmission.com/archive/Web%20Archives/ionpool.net%20(Dec-31-2020)/arcade/atari/roms.html)

## ROM Archives Present

This directory contains 45 `.zip` archives covering all supported variants
and additional prototypes/revisions. Each archive contains the individual
ROM chip files for one board revision.

The emulator's ROM loader extracts the required files from these archives
automatically. No manual extraction is needed.

## Missing Files

No files are missing. Archives cover all emulated variants.
