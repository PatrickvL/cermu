Atari Vector Program Data Archive

NOTE: THIS CODE IS ONLY FOR REPAIR OF CIRCUIT BOARDS

This is an attempt to archive all of the Atari vector game Data sets. These files contain all the appropriate location, size and checksum information. Please send me more if you have them! Special thanks to Jess Askey, Clay Cowgill, Mark Shostak, Scott Evans, Aaron Giles, Al Kossow, Owen Rubin, Scott Brasington and our MAME friends.
