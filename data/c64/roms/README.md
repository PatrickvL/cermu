# C64 ROMs Directory

This directory should contain the Commodore 64 system ROM files.

## Required Files

Place the following ROM files in this directory:

- `basic.rom` (8KB) - Commodore BASIC V2 ROM
- `kernal.rom` (8KB) - KERNAL operating system ROM  
- `char.rom` (4KB) - Character generator ROM

## Alternative Names

The emulator will also recognize these alternative filenames:
- `901226-01.bin` (BASIC ROM part number)
- `901227-03.bin` (KERNAL ROM part number)
- `901225-01.bin` (CHARGEN ROM part number)

## ROM Versions

Different C64 revisions used different ROM versions. The most common are:
- BASIC: 901226-01 (all C64 models)
- KERNAL: 901227-03 (most common), 901227-01 (early), 901227-02 (rare)
- CHARGEN: 901225-01 (most common)

## Checksums

You can verify your ROM files using these MD5 checksums:

### BASIC ROM (901226-01)

### KERNAL ROM (901227-03) 
- Size: 8192 bytes
- MD5: `39065497630802346bce17963f13c092`

### CHARGEN ROM (901225-01)
- Size: 4096 bytes  
- MD5: `adc7c31e18c7c7413d54802ef2f4193da6c8e6f1`
