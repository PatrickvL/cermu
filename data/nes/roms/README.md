# NES / Famicom ROM Directory

Game cartridge ROMs go here. The NES has no system ROMs — all software is
cartridge-based.

## Supported Formats

| Format | Extension | Description |
|--------|-----------|-------------|
| iNES | `.nes` | Standard cartridge ROM (header + PRG + CHR) |
| NES 2.0 | `.nes` | Extended iNES format with additional metadata |

## Where to Obtain

Game ROMs are copyrighted by their respective publishers and must be obtained
legally:

- **Dump from original cartridges** — using a cartridge dumper (e.g. INLretro)
- **Homebrew games** — freely available:
  - [NESdev Homebrew](https://www.nesdev.org/wiki/Homebrew)
  - [NES Homebrew on itch.io](https://itch.io/games/tag-nes)
