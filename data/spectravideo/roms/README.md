# Spectravideo SVI ROM Files

The Spectravideo SVI-318 and SVI-328 require a BASIC ROM to boot. These
ROMs are copyrighted by Spectravideo and Microsoft (BASIC), and are
**not** included in this repository.

## Required ROMs

### SVI-318

| Filename | Size | Description |
|----------|------|-------------|
| `svi318.rom` | 32 KB | SVI-318 BASIC ROM |

### SVI-328

| Filename | Size | Description |
|----------|------|-------------|
| `svi328.rom` | 32 KB | SVI-328 BASIC ROM |

## Alternative Filenames Accepted

- **SVI-318:** `svi318.rom`, `SVI318.ROM`, `svi.rom`
- **SVI-328:** `svi328.rom`, `SVI328.ROM`, `svi.rom`

Both variants share this directory. The emulator selects the correct ROM
based on the system variant chosen at startup.

## Where to Obtain

- **MAME ROM set** — `svi318.zip` / `svi328.zip` contain the ROM images
- **Dump from original hardware** — if you own a Spectravideo computer
- **SVI community resources**
  - https://www.samdal.com/svi.htm
