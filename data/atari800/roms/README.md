# Atari 8-bit ROM Files

ROMs required by the Atari 800, 800XL, and 130XE emulation.

## Required ROMs

| Filename | Size | Description |
|----------|------|-------------|
| `atarixl.rom` | 16 KB | Atari XL/XE OS ROM ($C000–$FFFF) |

## Optional ROMs

| Filename | Size | Description |
|----------|------|-------------|
| `ataribas.rom` | 8 KB | Atari BASIC ROM ($A000–$BFFF) |

## Alternative Filenames Accepted

- **OS ROM:** `atarixl.rom`, `atariosb.rom`, `ATARIXL.ROM`, `ATARIOSB.ROM`
- **BASIC ROM:** `ataribas.rom`, `BASIC.ROM`, `ataribasic.rom`

## Missing Files

| Filename | Size | Description |
|----------|------|-------------|
| `atarixl.rom` | 16 KB | **MISSING** — Atari XL/XE OS ROM |
| `ataribas.rom` | 8 KB | **MISSING** — Atari BASIC (optional) |

## Where to Obtain

- **Atari800 emulator** — ships OS ROMs with permission from Atari
  - https://atari800.github.io/
- **MAME ROM set** — `a800xl.zip` or `a800.zip` contain the OS ROMs
- **Dump from original hardware** — if you own an Atari 8-bit computer
