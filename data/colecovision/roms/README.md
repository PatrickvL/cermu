# ColecoVision ROM Files

The ColecoVision requires a BIOS ROM to boot. This ROM is copyrighted
by Coleco Industries and is **not** included in this repository.

## Required ROMs

| Filename | Size | Description |
|----------|------|-------------|
| `coleco.rom` | 8 KB | ColecoVision BIOS ROM |

## Alternative Filenames Accepted

- `coleco.rom`, `colecovision.rom`, `COLECO.ROM`

## Where to Obtain

- **MAME ROM set** — `coleco.zip` contains the BIOS ROM
- **Dump from original hardware** — if you own a ColecoVision console
- **AtariAge ColecoVision forum** — community preservation resources
  - https://atariage.com/forums/forum/30-colecovision-colecoadam/
