# Dragon 32/64 ROM Files

ROMs required by the Dragon 32 and Dragon 64 emulation.

## Required ROMs

### Dragon 32

| Filename | Size | Description |
|----------|------|-------------|
| `d32.rom` | 16 KB | Dragon 32 BASIC ROM ($8000–$BFFF) |

### Dragon 64

| Filename | Size | Description |
|----------|------|-------------|
| `d64_1.rom` | 16 KB | Dragon 64 BASIC ROM ($8000–$BFFF) |

## Optional ROMs

| Filename | Size | Description |
|----------|------|-------------|
| `d64extbas.rom` | 8 KB | Dragon 64 Extended BASIC ROM ($8000–$9FFF) |

## Alternative Filenames Accepted

- **Dragon 32 BASIC:** `d32.rom`, `d64_1.rom`, `dragon32.rom`, `dragon64.rom`
- **Extended BASIC:** `d64extbas.rom`, `dragon64_extbasic.rom`

## Missing Files

| Filename | Size | Description |
|----------|------|-------------|
| `d32.rom` | 16 KB | **MISSING** — Dragon 32 BASIC ROM |
| `d64_1.rom` | 16 KB | **MISSING** — Dragon 64 BASIC ROM |

## Where to Obtain

These ROMs are copyrighted by Dragon Data Ltd and Microsoft.

- **MAME ROM set** — `dragon32.zip` or `dragon64.zip`
- **Dragon Archive** — community preservation site
  - https://archive.worldofdragon.org/
- **Dump from original hardware** — if you own a Dragon computer
