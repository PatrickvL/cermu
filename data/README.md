# Data Directory

This directory contains system-specific data files for the emulator, including
ROMs, cartridges, and other binary files. Each subdirectory has its own README
describing the required files and where to obtain them.

## Systems

| Directory | System | ROMs Required | Freely Distributable |
|-----------|--------|:---:|:---:|
| `apple1/` | Apple 1 | Monitor, Character, BASIC (opt.) | Yes (included) |
| `atari2600/` | Atari 2600 / VCS | Cartridge only | N/A |
| `bbc/` | BBC Micro Model B | OS, BASIC | No |
| `c16/` | Commodore C16 / C116 / Plus4 | BASIC, KERNAL | No |
| `c64/` | Commodore 64 | BASIC, KERNAL, CHARGEN | No |
| `chip8/` | CHIP-8 / XO-CHIP | Programs only | N/A |
| `nes/` | NES / Famicom | Cartridge only | N/A |
| `pet/` | Commodore PET 4032 | BASIC, Editor, KERNAL, CHARGEN | No |
| `spectrum/` | ZX Spectrum 48K / 128K | Spectrum ROM | Yes (48K included) |
| `vic20/` | Commodore VIC-20 | BASIC, KERNAL, CHARGEN | No |

## Legal Notice

Most system ROMs are copyrighted and are **not** included in this repository.
Exceptions are noted above and in the per-system README files.

You must obtain copyrighted ROMs legally from:
- Original hardware you own
- Licensed ROM collections (e.g. Cloanto C64 Forever)
- Emulator distributions that ship ROMs under license (e.g. VICE)
