# Commodore C16 / C116 / Plus/4 ROMs

Place the following ROM files in this directory:

| Filename                | Size  | Description                |
|-------------------------|-------|----------------------------|
| basic.318006-01.bin     | 16 KB | BASIC 3.5 ROM              |
| kernal.318004-05.bin    | 16 KB | Kernal ROM (PAL)           |

## Alternative filenames accepted

The ROM loader tries multiple filenames for each ROM:

- **KERNAL**: `kernal.318004-05.bin`, `kernal.rom`, `318004-05.bin`
- **BASIC**:  `basic.318006-01.bin`, `basic.rom`, `318006-01.bin`
