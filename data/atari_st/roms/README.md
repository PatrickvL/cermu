# Atari ST ROM Files

ROMs required by the Atari ST, STe, and Mega ST emulation.

## Included ROMs (EmuTOS — Free Alternative)

This directory includes **EmuTOS** (v1.3), a free open-source TOS replacement
licensed under the GPL. EmuTOS provides good compatibility with most Atari ST
software and is a drop-in replacement for the original TOS ROM.

| Filename | Size | Source | Description |
|----------|------|--------|-------------|
| `tos.img` | 192 KB | EmuTOS 1.3 (US) | TOS ROM image |

EmuTOS project: https://emutos.sourceforge.io/

## Required ROMs

| Filename | Size | Description |
|----------|------|-------------|
| `tos.img` | 192 KB | TOS (The Operating System) ROM image |

## Alternative Filenames Accepted

- `tos.img`, `tos104.img`, `tos102.img`, `TOS.IMG`

## Original TOS ROMs (Not Included)

For maximum compatibility, you can replace EmuTOS with an original TOS ROM:

- **MAME ROM set** — `st.zip` or `ste.zip` contain TOS ROMs
- **Dump from original hardware** — if you own an Atari ST
- **Hatari emulator** — documentation on obtaining TOS ROMs
  - https://hatari.tuxfamily.org/
