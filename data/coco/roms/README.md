# TRS-80 Color Computer (CoCo) ROM Files

ROMs required by the TRS-80 CoCo 1 and CoCo 2 emulation.

## Required ROMs

| Filename | Size | Description |
|----------|------|-------------|
| `bas13.rom` | 8 KB | Color BASIC 1.3 ROM ($A000–$BFFF) |

## Optional ROMs

| Filename | Size | Description |
|----------|------|-------------|
| `extbas11.rom` | 8 KB | Extended Color BASIC 1.1 ROM ($8000–$9FFF) |

## Alternative Filenames Accepted

- **BASIC:** `bas13.rom`, `bas12.rom`, `color.rom`, `BASIC.ROM`
- **Extended BASIC:** `extbas11.rom`, `extbasic.rom`, `EXTBASIC.ROM`

## Missing Files

| Filename | Size | Description |
|----------|------|-------------|
| `bas13.rom` | 8 KB | **MISSING** — Color BASIC ROM |
| `extbas11.rom` | 8 KB | **MISSING** — Extended Color BASIC ROM (optional) |

## Where to Obtain

These ROMs are copyrighted by Tandy/RadioShack and Microsoft.

- **MAME ROM set** — `coco.zip` or `coco2.zip` contain the BASIC ROMs
- **Color Computer Archive** — community preservation site
  - https://colorcomputerarchive.com/
- **Dump from original hardware** — if you own a CoCo
