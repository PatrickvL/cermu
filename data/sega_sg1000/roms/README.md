# Sega SG-1000 / SC-3000 ROM Files

The Sega SG-1000 and SC-3000 are cartridge-based systems with no built-in
BIOS ROM. Games are loaded directly from cartridge ROM images.

## System ROMs

No system BIOS ROM is required. The SG-1000 boots directly into the
inserted cartridge.

## Cartridge ROMs

Place cartridge ROM images (`.sg`, `.rom`, `.bin`) in this directory
or load them via the emulator's file menu.

## Where to Obtain

- **Dump from original cartridges** — if you own SG-1000 games
- **MAME ROM set** — `sg1000.zip` contains system metadata
- **SMS Power!** — Sega 8-bit community and documentation
  - https://www.smspower.org/
