# VIC-20 ROM Files

The VIC-20 requires three system ROMs. These are copyrighted by Commodore and
are **not** included in this repository.

## Required ROMs

| Filename | Part Number | Size | Address | Description |
|----------|-------------|------|---------|-------------|
| `characters.901460-03.bin` | 901460-03 | 4 KB | $8000-$8FFF | Character generator ROM |
| `basic.901486-01.bin` | 901486-01 | 8 KB | $C000-$DFFF | BASIC V2 ROM |
| `kernal.901486-07.bin` | 901486-07 | 8 KB | $E000-$FFFF | KERNAL ROM |

## Alternative Filenames Accepted

- **Character ROM:** `characters.901460-03.bin`, `chargen.rom`, `901460-03.bin`
- **BASIC ROM:** `basic.901486-01.bin`, `basic.rom`, `901486-01.bin`
- **KERNAL ROM:** `kernal.901486-07.bin`, `kernal.rom`, `901486-07.bin`

## Where to Obtain
