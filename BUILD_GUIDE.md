## System Requirements

### Windows
- **OS**: Windows 10 or newer
- **Compiler**: Visual Studio Build Tools 2022 or Visual Studio 2022
- **CMake**: 3.16 or newer
- **PowerShell**: For build scripts

### Linux
- **OS**: Ubuntu 18.04+, or equivalent

- **Libraries**: SDL2 development packages, OpenGL libraries

### macOS
- **OS**: macOS 10.14 or newer
- **Compiler**: Xcode Command Line Tools or Clang
- **CMake**: 3.16 or newer
- **Libraries**: SDL2, OpenGL frameworks

## Quick Start

### Windows (MSBuild - Recommended)
```powershell
# Navigate to project root
cd code/c

# Build using PowerShell script (recommended)
.\..\..\build.ps1 Release

# Or build manually
& "C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\MSBuild\Current\Bin\MSBuild.exe" aiemuc.sln /p:Configuration=Release
```

### Linux (Make via CMake)
```bash
# Navigate to project root
cd code/c

# Configure and build
mkdir -p build && cd build
cmake ..
make -j$(nproc)

# Or use CMake directly from source directory
cmake --build . --config Release -j$(nproc)
```

### macOS (Make via CMake)
```bash
# Navigate to project root
cd code/c

# Configure and build
mkdir -p build && cd build
cmake ..
make -j$(sysctl -n hw.ncpu)
```

## Build Systems Overview

The project supports multiple build approaches:

### 1. **CMake (Cross-platform, Primary)**
- **Description**: Modern, cross-platform build system
- **Generates**: Visual Studio projects (Windows), Unix Makefiles (Linux/macOS)
- **Benefits**: Single configuration, automatic dependency detection
- **Usage**: Recommended for new development and Linux/macOS

### 2. **MSBuild (Windows)**
- **Description**: Microsoft's native build system
- **Files**: `aiemuc.sln`, `*.vcxproj`
- **Benefits**: Deep Visual Studio integration, Windows-optimized
- **Usage**: Recommended for Windows development

### 3. **Unix Makefiles (Linux/macOS)**
- **Description**: Generated by CMake for Unix-like systems
- **Benefits**: Fast incremental builds, standard on Unix systems
- **Usage**: Automatically used when CMake detects Unix environment

## Platform-Specific Instructions

### Windows Build Instructions

#### Method 1: Using Build Scripts (Recommended)
```powershell
# PowerShell script (recommended)
.\build.ps1 [Release|Debug]

# Batch script (alternative)
.\build.bat [Release|Debug]
```

#### Method 2: Direct MSBuild
```powershell
# Full path to MSBuild (avoids PATH issues)
$MSBuild = "C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\MSBuild\Current\Bin\MSBuild.exe"

# Build solution
& $MSBuild aiemuc.sln /p:Configuration=Release /verbosity:minimal
```

#### Method 3: CMake on Windows
```powershell
# Configure for Visual Studio
cmake -B build -G "Visual Studio 17 2022" -A x64

# Build
cmake --build build --config Release

# Or use generated solution
& $MSBuild build\aiemuc.sln /p:Configuration=Release
```

#### Windows Environment Setup
1. **Install Visual Studio Build Tools 2022**
   - Download from Microsoft's official site
   - Ensure C++ build tools are selected
   - MSBuild path: `C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\MSBuild\Current\Bin\MSBuild.exe`

2. **PowerShell Syntax Notes**
   - Use `;` for command chaining (NOT `&&`)
   - Use `if ($?) { command }` for conditional execution
   - Use `& "path with spaces"` for executables with spaces

## Build Targets

### Executables
- **`c64emu`** - Console-based C64 emulator
- **`c64emu_gui`** - GUI C64 emulator with Dear ImGui interface (requires SDL2 + OpenGL)
- **`test_mos6510_basic`** - Basic MOS6510 CPU functionality tests

### Build Configurations
- **Debug** - Unoptimized, debug symbols, assertions enabled
- **Release** - Optimized, no debug symbols, assertions disabled
- **RelWithDebInfo** - Optimized with debug symbols
- **MinSizeRel** - Size-optimized release build

### Output Locations
- **Windows**: `bin\Release\` or `bin\Debug\`
- **Linux/macOS**: `bin/` directory in build folder

### CMake Build Options
```bash
# Enable/disable GUI build (auto-detected by default)
cmake -DBUILD_GUI=ON ..

# Set build type
cmake -DCMAKE_BUILD_TYPE=Release ..

# Custom install prefix
cmake -DCMAKE_INSTALL_PREFIX=/opt/c64emu ..
```

## Dependencies

### Core Dependencies (Always Required)
- **C99 Compiler** - GCC, Clang, or MSVC
- **CMake 3.16+** - Build system generator

### GUI Dependencies (Optional, auto-detected)
- **SDL2** - Cross-platform media layer
  - Windows: Included in `deps/sdl2/SDL2-2.30.10/`
  - Linux: Install via package manager (`libsdl2-dev`)
  - macOS: Install via Homebrew/MacPorts
- **OpenGL** - 3D graphics library (system-provided)
- **Dear ImGui** - Immediate mode GUI (included as submodule in `external/cimgui/`)

### Dependency Detection
The build system automatically detects available dependencies:
- If SDL2 and OpenGL are found: GUI build enabled
- If dependencies missing: Console-only build
- Local SDL2 takes precedence over system installation

## Troubleshooting

### Common Windows Issues

#### Issue: "msbuild is not recognized"
**Solution**: Always use full path to MSBuild:
```powershell
& "C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\MSBuild\Current\Bin\MSBuild.exe"
```

#### Issue: PowerShell vs Unix syntax
**Problem**: Using `&&` instead of `;`
**Solution**: Remember PowerShell syntax:
```powershell
# ✅ Correct
cd "path"; if ($?) { command }

# ❌ Wrong
cd "path" && command
```

#### Issue: C4244 compilation warnings as errors
**Solution**: Add explicit type casts:
```c
// ✅ Correct
uint8_t value = (uint8_t)some_int;

// ❌ Causes C4244
uint8_t value = some_int;
```

### Common Linux Issues

#### Issue: SDL2 not found
**Solution**: Install development packages:
```bash
# Ubuntu/Debian
sudo apt install libsdl2-dev

# CentOS/RHEL
sudo yum install SDL2-devel
```

#### Issue: OpenGL headers missing
**Solution**: Install Mesa development packages:
```bash
# Ubuntu/Debian
sudo apt install libgl1-mesa-dev libglu1-mesa-dev

# CentOS/RHEL
sudo yum install mesa-libGL-devel mesa-libGLU-devel
```

#### Issue: CMake version too old
**Solution**: Install newer CMake:
```bash
# Remove old version
sudo apt remove cmake

# Install from CMake website or snap
sudo snap install cmake --classic
```

### Common Cross-Platform Issues

#### Issue: Git submodules not initialized
**Solution**: Initialize submodules:
```bash
git submodule update --init --recursive
```

#### Issue: Build fails with linker errors
**Solution**: Clean and rebuild:
```bash
# CMake
rm -rf build/
mkdir build && cd build && cmake ..

# Windows
# Delete bin/, Release/, Debug/ directories and rebuild
```

## Build Verification Commands

### Windows (PowerShell)
```powershell
# Check MSBuild exists
Test-Path "C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\MSBuild\Current\Bin\MSBuild.exe"

# List built executables
Get-ChildItem "bin\Release\*.exe"

# Run GUI after successful build
if (Test-Path "bin\Release\c64emu_gui.exe") { .\bin\Release\c64emu_gui.exe }
```

### Linux/macOS
```bash
# Check dependencies
pkg-config --exists sdl2 && echo "SDL2 found" || echo "SDL2 missing"

# List built executables
ls -la bin/*.exe 2>/dev/null || ls -la bin/*

# Run tests
cd build && ctest
```
